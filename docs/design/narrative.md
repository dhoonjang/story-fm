**한 줄 요약: 이벤트 로그에 서사 가치를 태깅해 쌓고(메모리), 그걸 아크로

## 1. 서사 메모리

```ts
NarrativeEvent { id, date, type, actors[], summary,  // 1문장
                 salience: 1..5, arcId? }
```

- **소스**: 스킬 결과(판정 포함) · 경기 이벤트(원인 태그와 연결) · tick
  이벤트. 태깅은 GM이 모델 턴 말미에 경량 구조화 출력으로.
- **salience 기준**: 감정 강도 · 관계 변화 폭 · 성적 영향 · 희소성.
- **주입**: `salience × recency` 가중 상위 N개를 GM 컨텍스트에
  (→ [ai-manager §4](./ai-manager.md)).

## 2. 아크 — 시즌 서사의 골격

```ts
Arc { id, type, actors[], state: 'open'|'rising'|'climax'|'resolved', beats[] }
```

- MVP 아크 타입: **유망주 성장 / 라커룸 갈등 / 라이벌전 악연 / 순위 레이스 /
  감독 평판** (결정 #8 연동 — 감독 자신의 이야기도 아크다).
- GM이 메모리에서 아크 후보를 감지 → 개설 → 비트 적립 → 해소.
  **동시 활성 상한 3~4개** — 초점 유지, 컨텍스트 예산 보호.
- 아크는 데이터일 뿐 강제 이벤트가 아니다 — 코어 상태를 바꾸려면 반드시
  `apply_narrative_event` 경로 (overview §7: 사기·폼·관계만).

## 3. 중계 스타일 (@중계)

- 중계 생성은 **매치 티어**(DeepSeek — 결정 #12, → [economy.md
  §2](./economy.md))가 담당한다. 문법·태그 규칙은 티어와 무관하게 동일.
- **하이라이트 위주** — 이벤트 로그 전체 서술 금지 (가독성·리듬 목적).
- **원인 태그를 해설로 번역** — `wing_overload` → "측면 과부하가 만든
  골입니다". 태그 밖 원인 창작 금지 (→ ai-manager §6-3).
- 경기 맥락 따라 톤 변주 — 더비·강등 결정전은 과열, 소화 경기는 담백.
- **중계 상세도는 연출 선택** (결정 #12: 비용이 상세도를 결정하지 않는다) —
  경기 중요도·유저 선호에 따라 풀 중계 ~ 요약 중계. "끝까지 보자" 스킵 시
  요약 모드.

## 4. 다이제스트 (`advance_time` 보고)

- 큐레이션 3~5개: ① needsManager 이벤트(멈춘 이유) 우선 → ② 활성 아크의
  진행 비트 → ③ 캘린더 사실 (다음 일정).
- 기본 프레임: `@:` 내레이션(시간 경과 연출) → `@수석코치:` 브리핑.
- 전부 나열 금지 — 서사 가치 없는 것은 오피스 뷰에만 남는다.

## 5. 감독 극단 행동 대응 (결정 #9)

- **수용하되 반드시 반응한다** — 무반응·물타기 금지 (프롬프트에 명문화).
- 반응 = 즉각 연출 (그 자리의 공기) + 판정 (`ai-manager §3`) + **지연 결과**
  (다음 tick의 사기·관계, 언론 보도, 구단주 반응).
- 반응 강도 = 행동 수위 × 대상 페르소나 성향 × 감독 평판 맥락 (신망 높은
  감독의 분노는 충격, 낮으면 반발).

## 6. 시즌 에필로그

시즌 종료 시 1회 생성 (→ game-loop §7): 최종 순위 · 보드 평가 · 해소된/
미해소 아크 정리 · 트로피·업적 잠금 해제 연출 · 팀 내 수상 → **"시즌 회고"
장문** → 감독 커리어와 함께 저장. **미해소 아크는 다음 시즌으로 이월된다**
(결정 #15) — 시즌을 관통하는 장기 서사(라이벌 악연, 대기만성 유망주)가
게임의 정체성이 된다.

## 7. 톤 가이드

- **서비스 언어는 한국어** (결정 #10) — 서사·페르소나 말투·중계 모두 한국어
  기준. 축구 용어는 국내 중계 관용 표기(오프사이드, 클린시트, 스루패스).
- 기본: 진지한 스포츠 드라마. 유머는 페르소나에서 나온다 (기믹 금지).
- ⚠️ **실존 인물 폄하 서사 금지** — 실명 MVP의 안전선 ([personas
  §4](./personas.md)). 부정적 전개(갈등·불화)는 판정·상태가 만든 게임 내
  사실에서만 파생시키고, 실존 인물의 실제 평판을 훼손할 서사(범죄·추문
  창작 등)는 만들지 않는다.
- 문체: 중계는 현재형 단문, 일상은 지문 중심 — overview §2.1 표기 규약 준수.

## 8. 미해결

- 아크 감지 — 규칙 기반(이벤트 패턴 매칭) vs LLM 판단 vs 혼합
- 중계 페르소나 개성 (단독 캐스터 vs 캐스터+해설 듀오)
- 에필로그 분량·형식 (텍스트 단독 vs 오피스 뷰 연계 리포트)
- 서사 메모리 장기 압축 (시즌 후반 메모리 비대화 대응)
