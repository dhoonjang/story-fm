# 세계가 말을 건다 (Approaches)

> 지금 이 게임의 세계는 **감독이 말을 걸어야만** 반응한다. 훈련·전술·면담·이적 —
> 전부 감독이 먼저 손을 뻗는 손잡이다. 그래서 감독이 아무것도 하지 않으면 세계도
> 아무 일도 하지 않는다. 살아 있는 구단은 그렇지 않다.
>
> 이 문서는 **인물이 감독에게 먼저 말을 거는 통로**를 설계한다. 기자회견은 그
> 통로의 한 갈래일 뿐이다.

---

## 1. 선을 잘못 그었다 — "누가 문장을 쓰나"가 아니라 "누가 사실을 정하나"

기자회견 1차 구현은 질문 문장을 코어에 박아 두었다. 이유는 옳았다("모델이 질문을
지으면 세계에 없던 사건이 회견장에서 태어난다") 하지만 **선을 잘못 그었다.**

경계는 언제나 같다 (AGENTS.md 4장):

| | 코어 | LLM |
| --- | --- | --- |
| 경기 | 기대 득점 → 사건 확정 | 중계·연출 |
| 협상 | 성사 확률·근거 | 수락·역제안 판정 |
| 설득 | 주장이 **사실인가** | 그 논거의 무게 |
| **말 걸기** | **무엇이 사실인가 · 누가 말할 자격이 있나** | **그 사람이 실제로 뭐라고 말하는가** |

코어가 지켜야 할 것은 **사실**이지 **문장**이 아니다. 문장을 박아 두면 세 가지를
잃는다: ① 시즌 내내 같은 말이 반복된다 ② 화자의 성격(페르소나)이 문장에 닿지
못한다 ③ 맥락(더비인가, 감독이 어제 뭐라 했나)이 반영되지 않는다.

**그러므로: 코어는 사실 카드를 건네고, 인물의 말은 모델이 쓴다.**

---

## 2. 사실 카드 (WorldFact)

세계가 말할 수 있는 모든 것은 **장부에서 읽어낸 사실 한 줄**이다. 질문이 아니고,
평가도 아니다 — "무슨 일이 있었나"뿐이다.

```ts
WorldFact = {
  kind: "result" | "winless" | "slump" | "benched" | "contract" | "injury" |
        "arrival" | "departure" | "offer" | "psr" | "youth" | "morale" | ...
  /** 장부에서 읽은 한 줄 — 물음표가 없다 */
  text: string            // "웨스트햄전 1-3 패배 (홈)" / "리그 5경기 연속 벤치"
  refs: { playerId?, matchId?, negotiationId?, teamId? }
  salience: 1..5          // 이 사실이 얼마나 큰 일인가
}
```

사실은 **저장하지 않고 매 tick 파생한다** (`collectFacts(state)` — `views.ts`와 같은
결). 장부에 원본이 있는 것을 두 번 적으면 반드시 어긋난다.

> ⚠️ 사실 카드에 **평가어를 넣지 않는다.** "충격적인 참패"는 사실이 아니라 이미
> 기사다. 그 판단은 말하는 사람의 몫이고, 사람마다 달라야 화자가 살아난다.

---

## 3. 누가 이 사실에 반응하나 (INTEREST)

같은 사실도 사람마다 다른 이유로 걸린다. 이 표가 **말할 자격**을 정한다 — 모델이
"누가 말을 걸까"를 고르면 아무나 아무 때나 나타난다.

| 사실 | 말 거는 사람 | 그가 원하는 것 |
| --- | --- | --- |
| 5경기 연속 벤치 | 그 선수 → (오래되면) 에이전트 | 출전 기회 |
| 계약 만료 임박 | 그 선수 · 에이전트 | 재계약 조건 |
| 폼 바닥 · 연속 부진 | 수석코치 (걱정) · 기자 (추궁) | 설명 |
| 경기 결과 | 기자 | 해명·평가 |
| 연패 | 기자 → 구단주 | 대책 |
| 큰 영입·매각 | 기자 · 밀려난 선수 | 자기 자리 |
| 받은 오퍼 | 그 선수 · 에이전트 | 보내 달라 / 잡아 달라 |
| PSR 경고 · 적자 | 구단주 | 지출 축소 |
| 유망주 급성장 | 수석코치 | 기회를 주자 |
| 팀 사기 저하 | **주장** | 라커룸 이야기 |
| 부상 복귀 | 수석코치 · 그 선수 | 복귀 시점 |

**주장이 남을 대신해 말한다**는 항목이 중요하다 — 주장 지명이 지금은 사기 +15
한 번으로 끝나는데, 이 표에 들어오면 **주장이 실제로 하는 일**이 생긴다.

---

## 4. 압력 — 말할 거리는 하루아침에 생기지 않는다

사실이 있다고 곧장 말을 걸면 세계가 시끄러워진다. 사이에 **압력**을 둔다.

```ts
state.pressures: { speaker, topicKey, level, since, lastSpokeOn }[]
```

- 매일 tick이 사실을 훑어 관련 인물의 `level`을 올린다 (사실의 `salience`만큼).
- 임계를 넘고 쿨다운이 지났으면 **말을 건다**(Approach).
- 감독이 응하면 내려간다. **말로만 풀리지 않는다** — 벤치 불만은 선발로 세워야
  진짜로 내려가고, 면담은 시간을 벌 뿐이다. 그래야 감독의 말이 공짜가 아니다.
- 방치하면 계속 쌓여 **다음 계단으로 올라간다**(§6).

압력은 **저장한다** — 감독이 무엇을 했는지가 누적된 결과라 장부에서 파생할 수 없다
(`SETTLING_EVENT`과 같은 이유).

### 소음을 막는 세 개의 문

| 문 | 규칙 | 왜 |
| --- | --- | --- |
| 총량 | **하루 한 건** | 매일 누가 말을 걸면 감독이 자기 일을 못 한다 |
| 화자 | 같은 사람 7일 쿨다운 | 같은 선수가 사흘 내리 찾아오면 사람이 아니라 알림이다 |
| 주제 | 같은 주제는 **계단이 올라갔을 때만** 다시 | 되풀이는 압력이 아니라 잔소리다 |

## 5. 말 걸기 (Approach)

```ts
Approach = {
  id, date, expiresOn
  speaker: { kind: "player"|"coach"|"owner"|"press"|"agent"|"captain", id? }
  channel: "corridor"|"office"|"dressing_room"|"press_room"|"phone"
  facts: WorldFact[]      // 코어가 건넨 재료 — 모델은 이 밖을 묻지 못한다
  want: "play_time"|"explanation"|"reassurance"|"renewal"|"exit"|"spending"|...
  weight: 1..3            // 효과 한도가 여기에 비례
  status: "pending"|"answered"|"ignored"
}
```

**기자회견은 `channel: "press_room"`인 Approach다.** 지금의 `press.ts`는 이 구조에
흡수된다 — 회견만 특별 취급하면 같은 코드를 인물마다 다시 쓰게 된다.

채널이 장면의 결을 정한다: 복도에서 붙잡는 것과 감독실 문을 두드리는 것과 회견장에
앉는 것은 **같은 불만이라도 다른 사건**이다. 모델은 채널을 보고 장면을 쓴다.

### 화면에 어떻게 나타나나

채팅이 곧 화면이므로 **GM이 다음 턴에 장면으로 연다.** 상태 스냅샷에
`말을 걸어온 사람` 블록이 서고, 시간을 넘긴 턴이면 그 사이 열린 Approach가 장면이
된다(이미 "시점이 하루 이상 흘렀으면 그동안 벌어진 일 중 하나를 장면으로 열어라"는
규칙이 있다 — 그 "하나"에 우선권을 준다).

**열려 있는 Approach는 하나뿐이다.** 겹치면 salience가 큰 쪽이 서고 나머지는
압력으로 되돌아간다 — 사라지는 게 아니라 **나중에 더 크게 온다.**

## 6. 무시의 대가 — 사다리

무시가 공짜면 아무도 답하지 않는다. 하지만 **채널마다 대가가 다르다.**

| 채널 | 방치했을 때 |
| --- | --- |
| 회견장 | 즉시 언론 평판 하락 (의무 회견 불참은 실제로도 벌금·비판) |
| 복도·감독실 | 즉시 벌점은 없다. 대신 **압력이 한 계단 오른다** |

선수 한 명의 불만이 밟아 올라가는 계단 — 이것이 이 설계의 핵심이다:

```
① 수석코치가 대신 전한다      "스미스가 요즘 좀 답답해합니다"
② 선수가 복도에서 붙잡는다     "저 언제 나갈 수 있습니까"
③ 감독실 문을 두드린다         면담 요구 · 이 자리에서 답을 원한다
④ 에이전트가 전화한다          "다른 팀이 관심을 보입니다"
⑤ 언론에 말한다               평판(언론·선수단) 타격 · 라커룸 전체 사기
⑥ 이적 요청                    공개 요청 — 팔지 않으면 계속 깎인다
```

한 줄의 불만이 시즌 하나의 이야기가 된다. **감독은 어느 계단에서든 내려보낼 수
있지만, 위로 갈수록 말로는 안 되고 행동(출전·재계약·매각)이 필요하다.**

같은 사다리가 다른 인물에도 있다:

- **구단주** — 우려 → 경고 → 예산 동결 → 경질 논의
- **기자** — 질문 → 추궁 → 기사(평판) → 경질설 보도

---

## 7. 응답 — 도구 하나

"누가 말을 걸어왔고 감독이 답한다"는 **한 판단**이므로 도구도 하나다
(AGENTS.md — 한 판단은 한 도구로).

```
respond_to_approach(approachId, stance, intensity, targetPlayerId?, decline?)
```

`respond_to_media`는 여기에 흡수된다(도구 표면 유지). 스탠스 어휘는 회견에서
쓰던 다섯을 그대로 쓴다 — 감싸기·책임 인정·공개 비판·도발·말 아끼기. 회견장에서
통하는 태도의 축은 복도에서도 같다.

감독이 **먼저** 손을 뻗는 `talk_to_player`·`team_talk`은 그대로 남는다 — 부르는
것과 답하는 것은 다른 일이다.

### 효과

지금 회견이 쓰는 구조를 그대로 일반화한다 — 표 × `BAND` × `weight`, 사기 쪽만
리더십 계수. 다만 **닿는 곳이 화자에 따라 갈린다**:

| 화자 | 주로 닿는 곳 |
| --- | --- |
| 선수 | 그 선수 사기 · 압력 · (정착 중이면 정착 크레딧) |
| 주장 | 팀 전체 사기 · 선수단 평판 |
| 기자 | 언론 평판 · 지목된 선수 |
| 구단주 | 보드 평판 · (경우에 따라 예산) |
| 수석코치 | 거의 없다 — 정보 전달이 그의 일이다 |

## 8. 결정성 경계 (요약)

| 코어가 정한다 | LLM이 정한다 |
| --- | --- |
| 무엇이 사실인가 (사실 카드) | 그 사람이 실제로 하는 말 |
| 누가 말할 자격이 있나 (INTEREST) | 어떤 어조로 |
| 언제 말을 거나 (압력·쿨다운) | 장면의 연출 |
| 무시의 대가 · 사다리 | 감독 답의 스탠스 판정 |
| 효과의 폭 (한도) | — |

모델은 **사실 카드 밖의 사실을 말할 수 없다.** 철칙 3(모르는 것을 지어내지 마라)이
이미 그 계약이고, 사실 카드는 그 계약의 재료다.

## 9. 단계

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1 | **사실 카드** — 회견 질문 문장을 걷어내고 사실만 넘긴다. GM이 질문을 쓴다 | ✅ |
| 2 | **Approach 코어** — `collectFacts` · `INTEREST` · 압력 · 큐 · `respond_to_approach`. 회견을 흡수 | 🔽 |
| 3 | **사다리** — 방치가 계단을 올린다. 이적 요청·언론 인터뷰까지 | 🔽 |
| 4 | **구단주·주장 채널** — 보드 시스템과 함께 (game-overview §⑥ `respond_to_board`) | 🔽 |

## 10. 미해결

- **압력의 눈금** — 임계·증가량은 플레이로 잡아야 한다. 너무 낮으면 시끄럽고 너무
  높으면 세계가 조용하다. 분포 모니터링으로 검증한다 (AGENTS.md 6장 4항).
- **타 팀 인물** — 상대 감독의 도발, 노리는 선수의 에이전트. 우리 세계 밖 화자는
  `speakerRoles`가 자리를 모른다 (personas.md §6-1).
- **선수가 거절할 수 있는가** — 감독이 부른 면담을 선수가 피하는 경우. 사다리
  ⑤ 이상에서만 가능하게 할지.
