# 능력치 모델 (Attribute Model)

> 🚧 **초안 v0.2** · 2026-07-21 · [game-overview §6–7](./game-overview.md)의 심화
> — 6축 능력치 · 상태 보정 · 성장/쇠퇴 · 노출 규약 · 데이터 파이프라인 · 감독 능력치

**한 줄 요약: base 능력치(느린 변화) × 상태 보정(빠른 변화) = 유효 능력치.
변하는 경로는 훈련·경기·나이뿐이다 (결정 #7).**

---

## 1. Base 능력치

| 축 | EA FC 소스 필드 | 시뮬 사용처 (match-sim) |
| --- | --- | --- |
| pace | pace | 존 매치업, `pace_mismatch` |
| shooting | shooting | 찬스 해결 (마무리) |
| passing | passing | 점유 판정, 찬스 생성 |
| dribbling | dribbling | 찬스 생성 (돌파) |
| defending | defending | 수비 존 전력 |
| physical | physicality | 경합, 피로 내성 |

- 추가 필드: `overall`(파생 또는 EA), `potential`, 포지션 적성(EA
  `player_positions` → 주/부 포지션), 나이.
- **GK**: MVP는 EA 골키핑 종합 1축으로 축소.
- 스케일 0~99 유지. **MVP는 EA 값 그대로 시드** (🔴 라이선스 부채,
  [ADR 0001](../decisions/0001-mvp-real-data-deferred-licensing.md)) —
  출시 전 자체 산정 모델로 교체 ([data-sourcing §6 ③](./data-sourcing.md)).

## 2. 상태 (보정 계수)

| 상태 | 정의역 | 효과 초안 |
| --- | --- | --- |
| 폼 form | −3 ‥ +3 | 유효치 ±3%/단계 |
| 사기 morale | 0‥100 (기준 60) | ±0.15%/pt → 최대 약 ±6% |
| 피로 fatigue | 0‥100 | 60부터 페널티 가속, 부상 확률 가중 |
| 부상 | none / minor / major | 출전 불가 (minor 말기는 저성능 출전 허용 검토) |

```
유효 능력치 = base × (1 + formMod + moraleMod − fatigueMod)
```

- 계수는 밸런스 초안 — 시뮬 프로토타입에서 분포 보고 `balance.md`에서 튜닝.
- 페르소나는 이 계수에 직접 손 못 댄다 — 반드시 상태를 거친다 (overview §6).

## 3. 성장·쇠퇴 — 결정 #7: 이 경로가 전부

| 경로 | 규칙 초안 |
| --- | --- |
| 훈련 XP | 주간 포커스 배분 → 해당 축 XP. **나이 계수** ≤21 ×1.5 · 22–27 ×1.0 · 28–30 ×0.5 · 31+ 0. **potential 캡** 도달 시 정지 |
| 경기 XP | 출전 시간·평점 비례 소량 (훈련의 보조) |
| 포지션 전환 | `set_training_focus`의 개인 트랙 — 부포지션 적성 상승 (능력치와 별개 트랙) |
| 시즌 경계 | 나이 +1. 30+는 쇠퇴 롤 — pace·physical 우선 하락 (`PRNG(worldSeed, playerId, season)`) |

- 서사 이벤트(`apply_narrative_event`)는 **능력치 접근 불가** — 사기·폼·관계만
  (overview §7). "각성" 없음.

## 4. 부상 모델 (간이)

- **발생**: 경기(시뮬 틱 §match-sim 3-5)·훈련(daily tick) 확률, 피로 가중.
  전부 시드 파생.
- **규모**: minor 3~14일 / major 3~10주 (샘플 분포).
- **회복**: daily tick 감소, recovery조 지정 시 ×1.5 (→ game-loop §4-1).

## 5. 노출 규약 (결정 #2)

- **오피스 뷰**: 숫자 그대로 — 6축 0~99, 폼 화살표, 피로 바, 부상 아이콘.
- **채팅**: GM은 숫자를 읊지 않는다. 서술 밴드로 변환:

| 밴드 | 서술 예 |
| --- | --- |
| 90+ | "월드클래스", "리그를 씹어먹는" |
| 85–89 | "리그 최상위권" |
| 80–84 | "리그 정상급" |
| 75–79 | "준수한 주전감" |
| 70–74 | "스쿼드 자원" |
| ≤69 | "유망주" / "백업" (나이 맥락 반영) |

- 상대 팀 정보는 스카우트 리포트 경유 — 불확실성 서술("~로 추정") 허용.
  자팀은 확정 서술.

## 6. 데이터 파이프라인

```
EA FC CSV (Kaggle) ─┐
OpenFootball (팀·일정) ├─ 정규화 → internal_player_id 조인 (Wikidata 허브,
Wikidata (메타·ID)   ─┘   data-sourcing §5) → 시즌 스냅샷 → packages/domain 시드
```

- MVP는 **1회 적재 후 고정** — 라이브 갱신 없음. 시즌 진행에 따른 변화는
  전부 게임 내 성장 모델이 만든다.
- 적재 시 소스별 플래그(🟢/🔴) 유지 — 부채 청산 시 🔴만 걷어낼 수 있게
  (ADR 0001).

## 7. 감독 능력치 (결정 #13)

유저 캐릭터인 감독도 4축 능력치를 가진다 (0~99 — 선수와 같은 스케일).
구조는 **유저의 플레이 × 능력치 계수**: LLM은 발화·행동의 질을 판정하고,
그 효과가 능력치로 증폭·감쇠된다.

| 축 | 계수가 들어가는 공식 |
| --- | --- |
| 리더십 leadership | `team_talk`·`talk_to_player` 변화량 (→ ai-manager §3) · 선수 순응 — 사기·관계 반응 폭 |
| 전술 tactics | **전술 소화율** — TacticsSpec 보정이 시뮬 존 전력에 반영되는 강도 (→ match-sim §3) · 스카우트/분석 리포트 해상도 |
| 협상 negotiation | 거래형 판정 — 상대의 수락 문턱·역제안 폭 (이적/계약/보드 요구) |
| 미디어 media | `respond_to_media` 효과 · 평판 변동 폭 |

### 성장 — 쓰는 만큼 자란다

| XP 소스 | 축 |
| --- | --- |
| 면담·팀토크 양성 판정 | 리더십 |
| 전술 기인 이벤트 (원인 태그 `wing_overload` 등으로 득점/무실점) | 전술 |
| 협상 성사 (이적·계약·보드 합의) | 협상 |
| 미디어 대응 양성 판정 | 미디어 |

- **성공은 크게, 시도는 소량** — 실패한 팀토크도 경험은 된다.
- 변화량은 코어 공식 — LLM은 개입 불가 (overview §7 가드레일과 동일 원칙).
- 성장 곡선은 수확 체감 (낮을수록 빨리, 높을수록 느리게). 계수는 `balance.md`.
- **초기값은 유저가 직접 입력한 배경을 GM이 해석해 배분** (결정 #11) —
  자유 텍스트 배경 → 4축 배분 (합계 고정, Zod 검증). 예: "K리그에서 뛰다
  은퇴한 수비수" → 리더십·전술↑, "에이전트 출신 협상가" → 협상↑
  (→ game-loop §1).

### 노출

- 오피스(감독 프로필 카드)는 숫자 그대로, 채팅은 서술 — 결정 #2와 동일 규약.
- 성장 순간은 수치 알림 대신 서사로 연출 — *"선수단이 당신의 말에 귀
  기울이기 시작했다."* (→ narrative.md)

## 8. 미해결

- 상태 보정 계수·성장 속도 튜닝 (→ `balance.md`, 시뮬 프로토타입 후)
- GK 모델 확장 (선방 이벤트 해상도)
- 자체 능력치 산정 모델 설계 — 부채 청산 장치. 별도 문서(`rating-model.md`)
  승격 후보
- 감독 능력치의 상한 도달 시나리오 (모든 축 90+ 시 게임감 유지 방안)
