## 수치 초안 (balance.md 대상 — 코드가 현재 원본)

- 판정 공식: 팀토크 base −3~+3 × intensity/2 × 리더십 계수(0.7+lead/99×0.6), 이벤트당 사기 한도 ±6 (면담 ±8)
- 감독 XP: 100당 +1 (상한 90). 승리 리더십+10, 전술 기인 골 tactics+12/골, 팀토크 성공 8×강도
- 훈련 XP: 임계 25 → 능력치 +1, 나이 계수 1.5/1.0/0.5/0 (≤21/≤27/≤30/31+)
- 경기 반영: 폼 승+1/패−1(득점자 +1), 사기 승+4/무+1/패−4, 선발 피로 +34
- 시즌 전환: 30+ pace −1~3 · physical −0~2, 은퇴 35+ 또는 33+&OVR<72, 팀당 신인 max(1, 은퇴 수)
- 간이 시뮬: 홈 어드밴티지 ×1.06, λ = 1.4×(전력비)³ clamp 0.35~3.4

## 기술 결정

- TypeScript 6.x 고정 — TS 7(네이티브)을 typescript-eslint가 미지원
- 워크스페이스 상대 임포트는 확장자 없이 (Bundler 해석) — Next webpack 호환
- Next.js 15 App Router + React 19, 워크스페이스 패키지는 `transpilePackages`
- e2e: Playwright + mock GM 모드 (LLM 무의존). 실모드 검증은 스모크로 별도

## 적대적 리뷰 결과 (2026-07-22 — 52 에이전트 워크플로우)

5개 차원(코어 규칙·엔진 상태·LLM 경계·API/동시성·기획 정합) 파인더 + 발견별
반박 검증으로 47건 발견 → 39건 확인(중복 제거 시 ~25건). **확인된 결함은 전부
수정**했고, 각 수정에 회귀 테스트를 남겼다.

### 수정된 주요 결함

| 분류 | 결함 | 수정 |
| --- | --- | --- |
| 시즌 소프트락 | 유스에 GK가 없어 ~17시즌 후 GK 전멸 → 라인업 확정 불능 | 시즌 전환 시 그룹별 최소 인원(GK2·DF5·MF4·FW4) 강제 보충 (`season.ts`) |
| 성장 미반영 | 훈련·쇠퇴 후 overall 미재계산 → XI 선발·전력 패킷 왜곡 | `recomputeOverall` 도입, 훈련 +1·시즌 쇠퇴 직후 호출 |
| 유스 ID 충돌 | `season*10+i` 공식이 대량 은퇴 시즌에 ID 중복 생성 | `-y{season}-{i}` 형식으로 시즌 명시 |
| 출전 규칙 우회 | 부상·징계 선수가 선발/벤치/교체로 출전 가능 | `sanitizeUserLineup`(자동 대체) + `substitutePlayer` 경계 검증 |
| 카드 누적 부재 | 퇴장·경고 누적이 다음 경기에 무영향 | `seasonYellows`(5장→1경기)·`suspensions` 도입, `finalizeMatch`에서 정산 |
| 퇴장자 반영 누락 | 퇴장 선수가 경기 후 피로·폼 반영에서 빠짐 | `ledger.sentOff`를 출전자 집합에 합류 |
| 부상 RNG 채널 | `injury:{round}`에 시즌 미포함 → 시즌 간 동일 난수열 | `injury:{season}:{round}` |
| 경기 장부 | 하프타임 뒤 같은 배치 사건 허용, 킥오프 중복 허용, 교체 창 무제한 | 하프타임 강제 정지점, 킥오프 1회, 교체 창 3회(하프타임 제외) |
| 서사 스킬 | 부분 적용·무제한 호출 가능 | 전체 검증 후 일괄 적용(원자성) + 일일 3회 한도 |
| LLM 히스토리 | 턴 중단 시 tool_use 블록이 닫히지 않아 다음 턴 API 오류 | 합성 tool_result로 마감 (`anthropic-adapter.ts`) |
| 실모드 GM | idle GM에 대화 히스토리 미주입 → 맥락 단절 | `state.chat` 최근 12턴 주입, 경기 컨텍스트에 onPitch·교체 현황 포함 |
| mock 의도 오인 | 질문("언제 경기야?")이 advance_time을 발동 | 의도 정규식 강화 + 질문 감지 시 진행 차단 |
| API 경합 | 같은 게임 동시 턴이 저장을 상호 덮어씀 / 턴 실패 시 부분 커밋 | 게임별 뮤텍스 + 턴 시작 스냅샷 롤백 (`turn/route.ts`) |
| 시간 흐름 | 부상·불만 발생을 감독이 모른 채 지나감 | `advanceTime`이 `attention`으로 정지, GM이 보고 |

### 확인했지만 수정하지 않은 것 (by design / 허용)

- 실모드에 `advance_match` 스킬 없음 — 결정 #14 이후 캐스터 턴 자체가 진행
  단위라 별도 스킬이 불필요.
- mock GM은 한 메시지의 다중 의도 중 첫 분기만 처리 — mock은 테스트·오프라인용
  간이 구현이므로 허용.
- 경기 총 12골(팀당 6골 상한) 가능 — 극단값이지만 규칙 위반은 아님.
- 분당 이벤트 수 한도 없음 — 배치당 20개 한도로 갈음.
