# 페르소나 (Personas)

> 🚧 **초안 v0.1** · 2026-07-21 · [game-overview §6·§8](./game-overview.md)의 심화
> — 스키마 · 2계층 구조 · 감독 캐릭터 · 생성 파이프라인 · 기억

**원칙 (AGENTS.md 4장): 페르소나 = 코드가 아니라 데이터 (프롬프트 + 상태).**
페르소나는 시뮬 숫자에 직접 개입하지 않는다 — 반드시 상태(사기 등)를 거친다.

---

## 1. 스키마 (Zod 스케치)

```ts
Persona {
  characterId,           // == 채팅 @태그 (overview §2.1) — 전역 유일
  name, role,            // 'player' | 'head_coach' | 'owner' | 'journalist' | ...
  archetype,             // 템플릿 계층용 원형 (§2)
  traits: string[],      // 3~5개 — "야심가", "불같음", "충성파"
  motivation,            // 한 문장 — 이 인물이 원하는 것
  speechStyle,           // 말투 지문 + few-shot 대사 2~3개
  relationships: [{ targetId, type, score: -100..100 }],
  memory: NarrativeRef[],  // 개인 기억 (§5)
  seed,                  // 생성 재현용
}
```

## 2. 두 계층 — 깊게 소수, 얕게 다수

| 계층 | 대상 | 깊이 |
| --- | --- | --- |
| **핵심** | 수석코치 · 구단주 · 담당기자 + 자팀 선수 5~8명 | 풀 스키마 + 개인 기억 |
| **템플릿** | 그 외 전원 (자팀 나머지 + 타팀 전체) | archetype + traits 축약, 기억 없음 |

- **핵심 선수 자동 선발 규칙(초안)**: 주장 / 최고 overall(에이스) / 최연소
  고potential(유망주) / 최저 사기(불만분자) / 최고령(베테랑) — 중복 시 차순위.
- **서사 승격**: 시즌 중 사건의 중심이 된 템플릿 선수를 핵심으로 승격
  (자리 상한 유지, 장기 비활성 핵심은 강등). 규칙 상세는 미해결(§7).
- 타 팀 인물은 전부 템플릿 — 이적 협상 상대 단장도 archetype 연기.

## 3. 감독 — 플레이어 캐릭터 (결정 #8 · #13)

- 유저 생성 프로필(이름·배경) + **능력치 4축**(리더십·전술·협상·미디어 —
  → [attribute-model §7](./attribute-model.md)) + 시스템 기록: **평판
  3축**(보드 신뢰 · 언론 평판 · 선수단 신망) + **커리어 기록**(전적·수상·
  클럽 이력).
- **평판과 능력치는 다르다** — 평판은 세계가 감독을 어떻게 보는가(서사
  입력), 능력치는 감독의 행동이 실제로 얼마나 먹히는가(공식 계수). 평판은
  높은데 능력치가 낮은 "과대평가 감독" 같은 상태도 자연스럽게 존재한다.
- **GM은 감독을 절대 연기하지 않는다** — 유저 턴 전용 (overview §2.1 권한 경계).
- 평판·능력치 변동은 판정형 스킬 결과·성적이 공식으로 반영 (overview §7).

## 4. 생성 파이프라인

```
실측 데이터 (국적·나이·포지션·경력·시장가치)
  → archetype 분류 (규칙 기반)
  → 핵심 대상만 LLM 풀 생성 (1회) → Zod 검증 → 고정 저장
```

- **매 대화 생성 금지** — 일관성과 비용 (overview §6). `seed` 저장으로 재현 가능.
- **생성 언어는 한국어** (결정 #10) — 말투·인터뷰 톤 모두 한국어 기준.
  실명 외국인 선수도 한국어 중계 문맥의 표기를 따른다.
- **시즌 전환의 합성 신인**(→ game-loop §7)도 같은 파이프라인으로 생성 —
  실측 데이터 대신 생성 프로필(능력치+페르소나)에서 출발한다.
- 생성 프롬프트는 `packages/agents`에 버전 관리 (AGENTS.md 6-5).
- ⚠️ **실명 선수 + 가상 성격·대사 = NIL 부채 가중** ([data-sourcing
  §7](./data-sourcing.md)). 부정적 실명 서사 금지 가드(→ narrative.md §7)와
  세트로만 운용. 정식 출시 전 가명 전환 필수.

## 5. 기억 — 전역과 개인

| 종류 | 내용 | 소유 |
| --- | --- | --- |
| 전역 서사 메모리 | 세계의 사건 기록 (→ narrative.md §1) | 세계 |
| 개인 기억 | 자신이 관련된 사건의 1문장 요약 + 감정가 | 핵심 페르소나만 |

- 주입: 해당 캐릭터 발화 생성 시 최근·중요 상위 N개만.
- 관계 `score`는 **코어 상태**(스킬·tick이 공식으로 갱신) — 기억은 그 서사적
  근거다. 숫자와 이야기의 분리 (overview §7).

## 6. 말투 일관성

- `speechStyle` 지문 + few-shot 대사 2~3개를 발화 생성 컨텍스트에 항상 포함.
- 비용: 핵심 페르소나만 로드, 장면에 등장하는 인물만 (→ economy.md).

## 7. 미해결

- 핵심 승격/강등 규칙 상세 (자리 수, 판정 기준)
- **타 팀 감독 처리** — 실존 감독도 NIL 대상. 실명 유지 vs 가명 vs 익명
  ("첼시 감독") — data-sourcing 부채와 연동해 결정 필요
- 구단주 archetype 세트 (인내형/성과형/쇼맨십형 …)
- 페르소나 간 관계 초기값 생성 규칙 (국적·나이대·포지션 경쟁 기반)
