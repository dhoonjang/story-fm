# story-fm — 전체 구조

story-fm은 자연어로 감독이 되어 구단의 일상과 축구 경기를 이어 가는 게임이다.
유저는 감독을 맡고 GM은 선수·스태프·구단주·기자와 세계를 연기한다.

## 0. 용어

- **스킬**: GM이 직접 호출하는 도구.
- **출력 스키마**: 보조 에이전트가 반환하는 검증 가능한 구조.
- **코어 명령**: 검증된 인자로 실제 상태를 변경하는 결정적 함수.

## 1. 세 가지 경험과 공통 정보

메인 GM은 훈련·일상·면담·언론·보드와 감독의 커리어를 전개한다.
협상 GM은 협상 건 하나의 모든 상대를 연기하고 제안과 동의를 기록한다.
매치 GM은 코어가 확정한 경기 사건을 중계하고 감독의 전술 지시를 전달한다.
장면의 등장인물·갈등·관계·감정은 대화 맥락에서 판단한다.

이야기는 [로어북과 대화 요약](story/lorebook.md)에 보존한다.
로어북은 이름·키워드·한 줄 설명·자유 정보를 갖는다. 관계·불만·감정과 사건의 의미는
이 자유 정보에 기록하며 별도의 점수나 자동 서사 단계로 판정하지 않는다.

코어는 선수 능력·몸 상태·폼·적응, 전술·훈련·경기 결과와 계약·재정·고용을 기록한다.
숫자와 실제 실행 결과는 해당 원장이 원본이다. 모델의 서술만으로 원장을 바꾸지 않는다.

## 2. 한 턴이 지나가는 길

1. 서버가 게임 잠금 안에서 최신 세이브와 유저 입력·구조화 조작을 읽는다.
2. 현재 GM의 고정 프롬프트·참조 정보·이력·현재 상태를 조립한다.
3. 최근 모델 발화와 유저 입력의 키워드에 맞는 로어북을 유저 메시지 끝에 넣는다.
4. GM이 필요한 스킬을 호출한다. 지시 해석기는 원문에서 인자를 선택하고 코어가 검증·실행한다.
5. GM이 실행 결과와 대화 맥락으로 장면을 작성한다. 경기 시작은 장면 대신 입장 게이트를 반환한다.
6. 턴과 편집 요청을 저장하고 로어북 편집을 비동기로 실행한다. 이력 예산이 넘으면 요약한다.

같은 버전의 로어북이 현재 이력에 있으면 중복 주입하지 않는다. 편집되거나 주입 턴이
압축 범위에 들면 다음 키워드 일치 때 다시 주입한다. 요약은 최대 30명의 이름·한 줄 설명을
후보로 남기며 로어북을 편집하지 않는다.

## 3. 채팅 문법

감독 발화, 인물 대사, 서술과 구조화된 호출 결과가 한 채팅에 놓인다.
날짜·시간과 경기 사건은 코어의 기록에서 표시한다. 호출 결과는 `brief`의 항목을 읽으며
요약 문장을 파싱해 상태를 만들지 않는다. 정확한 장면 문법은
[프롬프트 규약](common/llm/prompts.md)이 소유한다.

## 4. 게임 루프

시즌은 7월 1일 시작해 프리시즌·리그·컵·유럽 대회를 거쳐 다음 시즌으로 전환한다.
날짜 진행은 훈련·다른 구단 경기·부상 회복·징계·재정·계약 만료 등 축구 사실을 정산한다.
유저의 라이브 경기는 브라우저 공간 시뮬레이터가 실행하고 서버가 체크포인트를 검증한다.
다른 경기와 간이 결산은 결정적 xG 시뮬레이션을 사용한다.

선수 계약은 초기 시드와 유스 첫 계약으로 생성한다. 모든 구단의 만료 선수는 무소속으로
이동한다. 선수 영입·매각·재계약은 [협상 화면](negotiation/README.md)에서 독립된 자연어 대화와 조건 확인으로 진행한다. 시즌 전환은 유스와
포지션별 최소 인원 보충으로 선수단을 구성한다.

감독·스태프의 고용은 메인 GM의 명시적인 제안·합의·수락과 코어 검증으로 처리한다.
감독은 무직 상태에서도 세계와 대화를 이어 갈 수 있다.

## 5. 화면

화면은 스토리 채팅·경기와 선수단·달력·대회·재정·커리어·협상 패널을 조립한다.
에이전트 센터는 다른 장부와 같은 위치에서 선수 검색·이적 문의, 진행 중인 협상, 계약 만료 예정과 우리 팀 이적 명단을 모아 보여준다. 건을 선택하면 메인 채팅 자리에서 자연어로 협상하며, 조건 요약·합의·메디컬·서명은 같은 대화 안에서 확인한다. 메인 대화로 돌아가면 기존 초안과 스크롤이 복원된다. 메인 GM, 센터의 문의, 세계 구단의 접근은 같은 협상 코어를 사용한다.
선수 이름을 누르면 같은 선수 카드가 열리고 경기 중에는 전술판과 라이브 경기 화면을 쓴다.
화면 조작과 자연어 지시는 같은 검증 경계를 통과한다.
재정은 잔고·수입·지출·월간 보고서·구장 증설을 표시하고 커리어는 계약·제안·공석·성적을 표시한다.

## 6. 세계와 저장

카탈로그는 새 게임의 기본값이고 세이브는 해당 게임의 상태다. 진행 중 카탈로그 편집은
이미 시작한 게임의 상태를 덮어쓰지 않는다. 경기·시즌·수상·고용 기록은 소유 ID를 유지한다.
저장 형태는 `SAVE_VERSION`, 모델 입력은 `config/game-version.yml`로 구별한다.
다른 저장 버전은 거부하며 마이그레이션하지 않는다.

## 7. 현재 구현 범위

온보딩·채팅·훈련·전술·실시간 경기·대회·시즌 전환·다년 진행을 지원한다.
협상 목록·이적·재계약·메디컬과 세계 시장, 로어북 검색·비동기 편집·대화 요약, 감독과 스태프의 고용, 명시적인 은퇴 선언,
구장 증설과 재정 원장을 제공한다. 인물의 반응과 관계는 GM과 자유 기록이 소유한다.
