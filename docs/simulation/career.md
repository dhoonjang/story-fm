# 커리어 — 감독으로 산다는 것

**감독은 스탯 다섯 개와 눈 셋을 가진 캐릭터다.** 능력치 5축은 감독이 하는 일에 곱으로
걸리고, 평판 3축은 세계가 그를 보는 눈이며, 보드는 그 둘을 보고 자리를 정한다. 배경
텍스트 한 문단이 출발점을 만들고, 시즌마다 기록이 쌓인다.

## 1. 캐릭터 생성 — 배경 텍스트가 능력치가 된다

새 게임은 셋을 받는다: **1부 리그 팀**(부임 구단) · 감독 이름(1~~30자) · **자유 텍스트
배경**(1~~500자). 배경은 정규식 휴리스틱(`interpretBackgroundHeuristic`)이 읽어 5축을
배분한다 — **순수 함수라 같은 배경과 같은 팀이면 언제나 같은 능력치**이고, LLM은 여기에
관여하지 않는다.

```
축값 = clamp( max(커리어 기준선, 부임 구단 하한) + 전문 분야 가산 × 축소비 )
```

| 커리어 등급 | 기준선 | 읽는 신호                                          |
| ----------- | ------ | -------------------------------------------------- |
| `elite`     | 58     | 우승·트로피·챔피언스리그·국가대표·발롱도르·빅클럽  |
| `major`     | 50     | 5대 리그·프리미어리그·라리가·수석코치              |
| `minor`     | 42     | 선수·주장·코치·유소년·해설·분석·에이전트·하부 리그 |
| `none`      | 34     | 축구 경력이 읽히지 않는다                          |

- **무대가 등급의 상한을 정한다** — `elite` 신호가 있어도 무대가 K리그·하부·아마추어
  뿐이면 `major`로 내려온다. "K리그 우승 감독"과 "챔피언스리그 우승 감독"은 다르다.
- **부임 구단은 가산이 아니라 하한**이다(tier 1 = 50 · 2 = 46 · 3 = 42 · 4 = 34).
  맨시티는 무경력자를 데려오지 않으므로 그 구단이 뽑았다는 사실 자체가 이력에 대한
  정보다. 하한이라 챔스 우승자가 승격팀에 부임해도 깎이지 않는다.
- **전문 분야는 축별 가산**이다: 리더십 +10(주장·포지션·은퇴) / +6(감독·지도자·유소년) ·
  전술 +12(전술·포메이션·빌드업·세트피스) / +4(프로·1군) · 협상 +12(에이전트·단장·
  비즈니스) · 분석 +12(분석·데이터·스카우트·통계) · 훈련 +12(피지컬·재활·컨디셔닝).
  합이 **`SPECIALTY_BUDGET` 30**을 넘으면 비례 축소된다 — 한 축에 몰면 +30, 셋에 나누면
  +10씩.
- 시작 범위는 **20~80**이고 **총합은 고정이 아니다**. 성장 상한(90)과 다르다.
- 시작 평판은 셋 다 **50**, `managerXP`는 전 축 0.
- ⚠️ **키워드 표에서 축끼리 같은 낱말을 나눠 갖지 않는다** — 한 마디가 두 축을 올리면
  특화 예산이 조용히 두 배가 된다(`specialtyAxesOf` 테스트가 막는다).

첫 장면은 GM이 쓰고, 실패하면 게임 자체가 만들어지지 않는다
([../llm/agents.md](../llm/agents.md) §2).

## 2. 능력치 5축 — 무엇에 곱해지는가

0~99, 화면 순서는 리더십 → 전술 → 훈련 → 협상 → 분석.

| 축     | 걸리는 자리                                                       | 폭                                                                               |
| ------ | ----------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 리더십 | 팀토크·면담·기자회견의 사기 변화량 (조기 소집 반발은 `2 −` 이 값) | `0.7 + (축/99)×0.6` = 0.70~1.30                                                  |
| 전술   | 존 전력 전체(`tacticalFit`)                                       | 0.92~1.08                                                                        |
|        | 지시 소화율(`instructionUptake`)                                  | `0.45 + 0.35×(축/99) + 0.20×팀 적응도` = 0.45~1.00                               |
|        | 키포인트 **정밀도**                                               | 선명도 `(축/99)×0.75 + min(0.25, 중요도/60)`, 0.55 넘으면 이름·수치가 붙는다     |
| 분석   | 키포인트 **개수**                                                 | `clamp(round(2 + (축/99)×8), 2, 10)` — 30이면 4개, 85면 9개                      |
|        | 경기 중 체력 안개                                                 | 오차 × `1 − (축−1)/98 × 0.65` (99면 `ANALYSIS_FLOOR` 0.35배)                     |
| 협상   | 딜 확률 기여 (`\|축−50\| ≥ 5`일 때)                               | 영입 `(축−50)/100`을 **구단·선수 두 관문 모두**, 매각·재계약 `/100`, 임대 `/120` |
| 훈련   | 훈련 결산의 **흡수율** — 적응도·능력치가 실제로 남는 폭           | `0.75 + (축/99)×0.25` = 0.75~1.00                                                |
|        | 한 결산에서 능력치가 움직이는 **인원**                            | `clamp(round(3 + (축/99)×3), 3, 6)` — 34면 4명, 90이면 6명                       |

- **지시 소화율은 이 게임에서 "유저의 지시가 100% 통하지 않는다"의 유일한 관문**이다.
  이득에만 곱하고 대가는 온전히 남는다 ([match.md](./match.md) §1.2). 경기 중에는
  `uptake + (1−uptake)×0.5`로 좁혀진다.
- **팀토크는 ±6, 면담은 ±8**이 이벤트당 한도다. 기자회견의 사기 파급도 같은 계수를 탄다.
- 사기 1점은 폼 `1/36`로 환산한다. 기존 체력 보정과 같은 즉시 전력 폭을 유지하면서
  몸의 피로는 건드리지 않는다.
- **분석은 개수, 전술은 정밀도** — 같은 판을 두고 분석이 "몇 개를 보는가"를, 전술이
  "얼마나 또렷하게 보는가"를 정한다. 크게 벌어진 짝은 눈이 어두워도 또렷하다.
- **훈련은 흡수율이라 1을 넘지 않는다.** 판정이 정한 폭(적응도 −1~3 · 능력치 ±1)을
  감독이 뚫으면 "한 번에 게임을 크게 흔들지 않는다"는 결산의 계약이 흐려진다
  ([player.md](../data/player.md) §7). 좋은 감독은 **덜 흘리는** 쪽이고, 대신 한 결산이
  **몇 명에게 남는가**를 함께 정한다 — 훈련장이 넓어지는 것은 인원으로 보인다.
- 상대 벤치의 눈은 패킷에 없다 — `managerAnalysis`는 **우리 팀에만** 실린다.
- AI 감독은 축이 하나뿐이다(`TEAM.aiManagerTacticsRating`, 초기 55~82).

## 3. 성장 — 쓰는 만큼 오른다 (`managerXP`)

축마다 XP가 쌓이고 **100에 닿으면 그 축이 +1**, 100이 차감된다(`grantManagerXP`).
상한은 **90**이고, 닿은 뒤에는 XP만 쌓인다.

| 사건                   | 축     | XP                    |
| ---------------------- | ------ | --------------------- |
| 팀토크가 잘 먹혔다     | 리더십 | 8 × 강도 (8·16·24)    |
| 면담이 잘 풀렸다       | 리더십 | 6 × 강도 (6·12·18)    |
| 팀토크·면담이 실패했다 | 리더십 | 2                     |
| 경기 승리              | 리더십 | 10                    |
| 전술이 근거로 붙은 골  | 전술   | `min(30, 골 수 × 12)` |
| 영입·매각 타결         | 협상   | 15                    |
| 임대·재계약 타결       | 협상   | 7                     |
| 스카우트 보고서 도착   | 분석   | 8                     |
| 훈련 결산 한 구간      | 훈련   | 소화된 세션 수 × 0.5  |

전술 XP의 근거는 골 이벤트의 **원인 태그**(`MatchEvent.causes`)다 — 코어가 패킷 항목에서
뽑은 것이라 검증 없는 자유 문자열이 XP가 되지 않는다 ([match.md](./match.md) §4).

**축마다 자라는 길이 하나씩 있다** — 리더십은 말, 전술은 경기, 협상은 타결, 분석은
보고서, 훈련은 훈련장. 열심히 굴린 축은 시즌에 리더십·전술이 +3~8, 나머지 셋이 **+1.5~2**
오른다. 뒤의 셋이 절반인 것은 의도다: 주축은 여전히 경기장에서 자란다.

- **협상은 타결에만 붙는다.** 오퍼를 넣는 것은 공짜라, 넣기만 해도 오르면 아무 선수에게나
  1파운드를 부르는 것이 훈련이 된다.
- **훈련은 결산 횟수가 아니라 세션 수로 센다.** 결산당 고정값이면 `advance_time`을 하루씩
  쪼개는 것만으로 XP가 불어난다 — 세션 수는 어떻게 쪼개도 같다. 소수로 쌓이고 100에서
  한 칸이 되는 것은 다른 축과 같다.

## 4. 평판 3축 — 세계가 보는 눈

보드 · 언론 · 선수단, 각 0~100. **능력치와 다른 물건이다** — 능력치는 감독이 가진 것,
평판은 세계가 그를 보는 눈이다(그래서 `media`는 평판에만 남아 있다).

| 무엇                       | 보드            | 언론     | 선수단  |
| -------------------------- | --------------- | -------- | ------- |
| 경기 승 / 패               | +2 / −2         | —        | +2 / −2 |
| 시즌 리뷰 (기대 충족/미달) | +8 / −8         | —        | —       |
| 유럽 대항전 우승 / 결승    | +10 / —         | +10 / +4 | —       |
| 국내 컵 우승 / 결승        | +6 / —          | +8 / +3  | —       |
| 보드 경고                  | −6              | —        | —       |
| 기자회견                   | 스탠스별 (아래) |          |         |

**기자회견이 평판을 움직이는 유일한 판정형 스킬이다** — 팀토크·면담은 사기만 건드린다.
폭은 `PRESS_BAND`(4) × 회견 무게(1~3), 즉 최대 ±12다.

| 스탠스                 | 보드 | 언론 | 선수단 |
| ---------------------- | ---- | ---- | ------ |
| 감싸기(`defend`)       | −0.2 | −0.4 | +1.0   |
| 책임 인정(`own`)       | +0.6 | +0.2 | +0.6   |
| 공개 비판(`criticise`) | +0.3 | +0.8 | −0.9   |
| 도발(`bold`)           | −0.3 | +1.0 | +0.4   |
| 말 아끼기(`deflect`)   | 0    | −0.3 | 0      |
| **방치·거절**          | −0.3 | −1.0 | +0.2   |

**공짜인 스탠스는 없다.** 무게는 성적 압박(최근 4경기 중 3경기 무승)이면 3, 큰 이적이면
2, 그 밖엔 1~2다. 상세는 [../data/people.md](../data/people.md).

평판을 **읽는** 자리는 셋이다 — 영입 협상에서 `(언론+보드)/2`, 재계약에서
`(언론+선수단)/2`, 설득 논거 `manager_reputation`에서 세 축 평균(60 이상이어야 통한다).

## 5. 보드와 자리 — 경고가 먼저, 경질은 나중

기대치는 구단 등급이 정한다. **난이도는 별도 옵션이 아니라 이 표다.**

| 팀 tier           | 보드 기대           | 위험 순위 | AI 감독이 잘리는 순위 |
| ----------------- | ------------------- | --------- | --------------------- |
| 1 (빅클럽)        | 2위 — 우승 경쟁     | 6         | 10                    |
| 2 (상위권)        | 6위 — 유럽 대항전권 | 10        | 14                    |
| 3 (중위권)        | 12위                | 15        | 18                    |
| 4 (승격팀·잔류권) | 17위 — 잔류         | 18        | 20                    |

**감독의 자리**(`reviewUserSeat` — tick이 매일 본다):

1. 리그 12경기를 치르기 전에는 보지 않는다.
2. **순위가 기대 목표 이내면 경고가 하나 지워진다** — 되돌릴 수 있어야 압박이 이야기가
   된다.
3. 순위가 **위험 순위 이하로 처졌고**(표의 숫자보다 아래) **마지막 경고로부터 한 달**이
   지났으면 경고한다 — 보드 평판 −6, 최대 3회.
4. **경고 3회째 + 리그 19·20위 + 보드 평판 25 이하**가 모두 겹칠 때만 경질된다.
   `state.dismissal`이 서면 **시계가 멈춘다** — `advanceTime`이 영구히 막힌다.

**경고 횟수는 화면에 서 있다.** 커리어 화면의 머리글이 세 칸으로 그리고(찬 칸이 받은
경고다), GM의 `get_career`도 같은 숫자를 말한다. digest 한 줄은 지나가지만 카운터는
남아야 한다 — 끝이 예고 없이 오면 사건이 아니라 사고다.

⚠️ **이 문턱은 AI보다 훨씬 관대하고, 그 비대칭은 의도한 것이다** — 아직 새 구단에
부임하는 길이 없어 **경질이 곧 세이브의 끝**이기 때문이다. 같은 문턱을 쓰면 우승 경쟁이
기대인 구단에서 10위만 해도 시즌 중에 게임이 끝난다.

**AI 구단의 벤치도 바뀐다**(`runManagerMarket`) — 부임 75일이 지나고 8경기를 치른 구단이
등급별 문턱 아래로 처지면 하루 **9%** 확률로 결단한다(하루 2건 상한). 후임은 새 이름과
새 전술 역량치(이전 값 + `randInt(−4, 10)`, 50~92로 자름)를 갖고, **새 감독 효과**로 그 선수단의
체력이 +6 · 폼이 +0.1 오른다. 우리 리그 안의 경질만 감독의 소식에 오른다.

## 6. 커리어 기록

| 기록            | 무엇이 남나                                                | 언제                                       |
| --------------- | ---------------------------------------------------------- | ------------------------------------------ |
| `SEASON_RECORD` | 시즌 · 팀 · 최종 순위 · 승무패 · 득실 · **보드 평가 문장** | 시즌 리뷰                                  |
| `TROPHY`        | 시즌 · 대회 표시 이름 · 팀                                 | 리그 1위 · 유럽 대항전 우승 · 국내 컵 우승 |
| `ACHIEVEMENT`   | code · 이름 · 설명 · 시즌                                  | 시즌 리뷰의 조건 검사                      |

**시즌 리뷰(`reviewSeason`)가 한 자리에서 확정한다** — 최종 순위 → 보드 평가 문장과 평판
±8 → 리그 트로피 → 유럽·국내 컵 결산(트로피·평판·상금) → 리그 상금·성과 보너스 → 업적 →
`SEASON_RECORD` 적재. 그다음이 시즌 전환이다 ([season.md](./season.md) §7).

업적은 다섯이다: `champion`(1위) · `invincible`(38경기 무패) · `top4`(4위 이내) ·
`sharpshooter`(우리 팀 시즌 15골 이상 최다 득점자) · `survivor`(tier 4 구단으로 17위 이내).

**화면과 조회** — 커리어 뷰는 오각형(다섯 축) + 평판 막대 3줄 + **보드 경고 3칸** +
트로피 보관함 + 업적 + 시즌 기록 표다. 막대 다섯 줄은 값을 하나씩 비교하게 만들 뿐이고
도형은 모양 하나로 성향을 말한다. **다음 칸까지 남은 XP는 오각형의 축 위에** 얹는다 —
축값 옆에 서야 "이 축이 지금 자라는 중인가"가 그 자리에서 읽힌다. GM은 `get_career`로
같은 것을 읽는다 — **지난 시즌의 개별 경기 결과는 남지 않고 시즌 단위 요약만 있다.**

## 7. ⚠️ 불변식

- **온보딩 해석은 순수 함수로 남긴다.** 같은 배경·같은 팀이 다른 능력치를 내면 시작이
  운이 된다.
- **부임 구단은 하한이지 가산이 아니다.** 가산으로 바꾸면 빅클럽에서 시작하는 것이 곧
  더 나은 감독이 되는 것이 되고, 약팀에서 시작하는 서사가 손해가 된다.
- **경질 문턱은 새 구단 부임 경로와 한 몸이다** — 이직이 생기면 AI와 같아져야 하고,
  그전에 문턱을 조이면 세이브가 사고로 끝난다.
- **경고는 지워질 수 있어야 한다.** 되돌릴 수 없는 압박은 이야기가 아니라 카운트다운이다.
- **기대치는 등급 표에서만 온다.** 기대와의 *차이*로 재면 잔류가 기대인 구단은 꼴찌를
  해도 차이가 3이라 강등권 감독이 영원히 안 잘린다.
- **`SEASON_RECORD`·`TROPHY`는 팀 id를 함께 갖는다** — 감독이 팀을 옮겨도 기록이 감독에게
  남아야 한다.
- **평판과 능력치를 한 값으로 합치지 않는다.** 하나는 감독이 가진 것이고 하나는 세계가
  보는 눈이라, 합치면 "잘하는데 안 알려진 감독"이 표현되지 않는다.

## 8. 미해결

- **보드 요청·목표 시스템이 없다.** `competition/season.ts`의 `boardExpectation`이
  순위 목표 하나를 돌려주고 `market/manager-market.ts`가 경고·경질만 한다 — 구단주가
  무언가를 요구하는 길이 없다(설계는 [../data/people.md](../data/people.md)).
- **이직 경로가 없다** — `core/tick.ts`가 `state.dismissal`을 보면 진행을 멈출 뿐 새
  자리를 주는 코드가 없어, 경질이 곧 세이브의 끝이다. 스키마(`teamId`)는 준비돼 있다.
- **업적이 다섯뿐**(`competition/season.ts`의 `checkAchievements`)이고 `champion`의
  설명이 리그 이름으로 하드코딩돼 있다.
- 경질된 뒤의 화면이 없다 — `views/views.ts`도 `office.tsx`도 `dismissal`을 읽지 않아
  시계가 멈춘 세이브는 digest 한 줄로만 그 사실을 말한다.
- 전 축이 상한(`skills/index.ts`의 `MANAGER_ATTR_CAP` 90)에 닿은 시나리오의 게임감이
  검증되지 않았다.
