# 커리어 — 감독으로 산다는 것

**감독은 스탯 다섯 개와 눈 셋을 가진 캐릭터다.** 능력치 5축은 감독이 하는 일에 곱으로
걸리고, 평판 3축은 세계가 그를 보는 눈이며, 보드는 그 둘을 보고 자리를 정한다. 배경
텍스트 한 문단이 출발점을 만들고, 시즌마다 기록이 쌓인다.

## 1. 캐릭터 생성 — 배경 텍스트가 능력치가 된다

새 게임은 셋을 받는다: **1부 리그 팀**(부임 구단) · 감독 이름(1\~30자) · **자유 텍스트
배경**(1\~500자). 배경은 정규식 휴리스틱(`interpretBackgroundHeuristic`)이 읽어 5축을
배분한다 — **순수 함수라 같은 배경과 같은 팀이면 언제나 같은 능력치**이고, LLM은 여기에
관여하지 않는다.

```
축값 = clamp( max(커리어 기준선, 부임 구단 하한) + 전문 분야 가산 × 축소비 )
```

| 커리어 등급 | 기준선 | 읽는 신호                                          |
| ----------- | ------ | -------------------------------------------------- |
| `elite`     | 58     | 우승·트로피·챔피언스리그·국가대표·발롱도르·빅클럽  |
| `major`     | 50     | 5대 리그·프리미어리그·라리가·수석코치              |
| `minor`     | 42     | 선수·주장·코치·유소년·해설·분석·에이전트·하부 리그 |
| `none`      | 34     | 축구 경력이 읽히지 않는다                          |

- **무대가 등급의 상한을 정한다** — `elite` 신호가 있어도 무대가 K리그·하부·아마추어
  뿐이면 `major`로 내려온다. "K리그 우승 감독"과 "챔피언스리그 우승 감독"은 다르다.
- **부임 구단은 가산이 아니라 하한**이다(tier 1 = 50 · 2 = 46 · 3 = 42 · 4 = 34).
  맨시티는 무경력자를 데려오지 않으므로 그 구단이 뽑았다는 사실 자체가 이력에 대한
  정보다. 하한이라 챔스 우승자가 승격팀에 부임해도 깎이지 않는다.
- **전문 분야는 축별 가산**이다: 리더십 +10(주장·포지션·은퇴) / +6(감독·지도자·유소년) ·
  전술 +12(전술·포메이션·빌드업·세트피스) / +4(프로·1군) · 협상 +12(에이전트·단장·
  비즈니스) · 분석 +12(분석·데이터·스카우트·통계) · 훈련 +12(피지컬·재활·컨디셔닝).
  합이 **`SPECIALTY_BUDGET` 30**을 넘으면 비례 축소된다 — 한 축에 몰면 +30, 셋에 나누면
  +10씩.
- 시작 범위는 **20\~80**이고 **총합은 고정이 아니다**. 성장 상한(90)과 다르다.
- 시작 평판은 셋 다 **50**, `managerXP`는 전 축 0.
- ⚠️ **키워드 표에서 축끼리 같은 낱말을 나눠 갖지 않는다** — 한 마디가 두 축을 올리면
  특화 예산이 조용히 두 배가 된다(`specialtyAxesOf` 테스트가 막는다).

첫 장면은 GM이 쓰고, 실패하면 게임 자체가 만들어지지 않는다
([../llm/agents.md](../llm/agents.md) §2).

## 2. 능력치 5축 — 무엇에 곱해지는가

0\~99, 화면 순서는 리더십 → 전술 → 훈련 → 협상 → 분석.

| 축     | 걸리는 자리                                                       | 폭                                                                               |
| ------ | ----------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 리더십 | 팀토크·면담·기자회견의 사기 변화량 (조기 소집 반발은 `2 −` 이 값) | `0.7 + (축/99)×0.6` = 0.70\~1.30                                                 |
| 전술   | 존 전력 전체(`tacticalFit`)                                       | 0.92\~1.08                                                                       |
|        | 지시 소화율(`instructionUptake`)                                  | `0.45 + 0.35×(축/99) + 0.20×팀 적응도` = 0.45\~1.00                              |
|        | 키포인트 **정밀도**                                               | 선명도 `(축/99)×0.75 + min(0.25, 중요도/60)`, 0.55 넘으면 이름·수치가 붙는다     |
| 분석   | 키포인트 **개수**                                                 | `clamp(round(2 + (축/99)×8), 2, 10)` — 30이면 4개, 85면 9개                      |
|        | 경기 중 체력 안개                                                 | 오차 × `1 − (축−1)/98 × 0.65` (99면 `ANALYSIS_FLOOR` 0.35배)                     |
| 협상   | 딜 확률 기여 (`\|축−50\| ≥ 5`일 때)                               | 영입 `(축−50)/100`을 **구단·선수 두 관문 모두**, 매각·재계약 `/100`, 임대 `/120` |
| 훈련   | 훈련 결산의 **흡수율** — 적응도·능력치가 실제로 남는 폭           | `0.75 + (축/99)×0.25` = 0.75\~1.00                                               |
|        | 한 결산에서 능력치가 움직이는 **인원**                            | `clamp(round(3 + (축/99)×3), 3, 6)` — 34면 4명, 90이면 6명                       |

- **지시 소화율은 이 게임에서 "유저의 지시가 100% 통하지 않는다"의 유일한 관문**이다.
  이득에만 곱하고 대가는 온전히 남는다 ([match.md](./match.md) §1.2). 경기 중에는
  `uptake + (1−uptake)×0.5`로 좁혀진다.
- **팀토크는 ±6, 면담은 ±8**이 이벤트당 한도다. 기자회견의 사기 파급도 같은 계수를 탄다.
- ⚠️ **같은 선수의 면담은 하루에 한 번만 셈한다** (`PlayerState.talkedOn`). 그날 두 번째
  면담부터는 사기도 리더십 XP도 정착 크레딧도 서사도 움직이지 않고, 이미 이야기했다는
  말만 돌아간다. 한 경기는 하루 안에서 끝나므로 이것이 곧 경기당 한 번이다.
- ⚠️ **팀토크는 `occasion`마다 하루에 한 번이다** (`Manager.teamTalkedOn`). `occasion`은 그
  말을 꺼낸 **자리**다 — 경기 전 `pre` · 하프타임 `half` · 경기 후 `post` · 평시 `daily`.
  같은 자리의 두 번째 팀토크부터는 면담과 똑같이 아무것도 움직이지 않는다. 그래서 하루가
  셈하는 팀토크는 **최대 넷**이고, 그것도 그날 경기가 있어야 넷이다.
  하루 한 번으로 묶지 않고 자리마다 가른 것은 경기 전의 한마디와 하프타임의 한마디가 서로
  다른 순간이기 때문이다 — 묶으면 연타를 막는 대신 라커룸 장면 하나가 사라진다.
- **면담이 불만을 푸는 것은 잘 풀렸을 때뿐이다.** 사기가 **오른** 결과(`reassured`·
  `motivated`)만 방치 이슈를 지운다. `neutral`은 아무것도 아니었던 대화고, 실망·분노는
  불만을 키우지 지우지 않는다 — 결과와 무관하게 지우면 화를 내는 것도 불만 해소책이 된다.
- **`neutral` 면담은 정착을 움직이지 않는다.** 사기 델타가 0인 대화에는 방향이 없으므로
  크레딧도 0이다 (→ [player.md](../data/player.md) §9.3).
- ⚠️ **주장 완장의 체력 +4는 선수마다 첫 지명에만 붙는다** (`PlayerState.captainedOn`).
  완장은 몇 번이고 옮겨 다니지만 처음 채워지는 순간의 무게는 한 번뿐이다. 정착 크레딧
  15는 이미 소속 기간에 한 번이다 (→ [player.md](../data/player.md) §9.3).
- 사기 1점은 폼 `1/36`로 환산한다. 기존 체력 보정과 같은 즉시 전력 폭을 유지하면서
  몸의 피로는 건드리지 않는다.
- **분석은 개수, 전술은 정밀도** — 같은 판을 두고 분석이 "몇 개를 보는가"를, 전술이
  "얼마나 또렷하게 보는가"를 정한다. 크게 벌어진 짝은 눈이 어두워도 또렷하다.
- **훈련은 흡수율이라 1을 넘지 않는다.** 판정이 정한 폭(적응도 −1\~3 · 능력치 ±1)을
  감독이 뚫으면 "한 번에 게임을 크게 흔들지 않는다"는 결산의 계약이 흐려진다
  ([player.md](../data/player.md) §7). 좋은 감독은 **덜 흘리는** 쪽이고, 대신 한 결산이
  **몇 명에게 남는가**를 함께 정한다 — 훈련장이 넓어지는 것은 인원으로 보인다.
- 상대 벤치의 눈은 패킷에 없다 — `managerAnalysis`는 **우리 팀에만** 실린다.
- AI 감독은 축이 하나뿐이다(`TEAM.aiManagerTacticsRating`, 초기 55\~82).

## 3. 성장 — 쓰는 만큼 오른다 (`managerXP`)

축마다 XP가 쌓이고 **100에 닿으면 그 축이 +1**, 100이 차감된다(`grantManagerXP`).
상한은 **90**이고, 닿은 뒤에는 XP만 쌓인다.

| 사건                   | 축     | XP                    |
| ---------------------- | ------ | --------------------- |
| 팀토크가 잘 먹혔다     | 리더십 | 8 × 강도 (8·16·24)    |
| 면담이 잘 풀렸다       | 리더십 | 6 × 강도 (6·12·18)    |
| 팀토크·면담이 실패했다 | 리더십 | 2                     |
| 경기 승리 (친선 제외)  | 리더십 | 10                    |
| 전술이 근거로 붙은 골  | 전술   | `min(30, 골 수 × 12)` |
| 영입·매각 타결         | 협상   | 15                    |
| 임대·재계약 타결       | 협상   | 7                     |
| 스카우트 보고서 도착   | 분석   | 8                     |
| 훈련 세션 하나를 소화  | 훈련   | 0.5                   |

전술 XP의 근거는 골 이벤트의 **원인 태그**(`MatchEvent.causes`)다 — 코어가 패킷 항목에서
뽑은 것이라 검증 없는 자유 문자열이 XP가 되지 않는다 ([match.md](./match.md) §4).
**원인이 안 붙는 골도 있다** — 패킷에 그 편으로 기운 매치업도 키포인트도 전술 노트도 없는
경기다. 태그가 비면 전술 XP는 0이고, 그래야 "전술이 근거로 붙은 골"이 조건으로 선다.
**친선의 골은 세지 않는다** — 프리시즌은 시즌 장부에 남지 않는다
([season.md](season.md) §2).

**축마다 자라는 길이 하나씩 있다** — 리더십은 말, 전술은 경기, 협상은 타결, 분석은
보고서, 훈련은 훈련장. 열심히 굴린 축은 시즌에 리더십·전술이 +3\~8, 나머지 셋이 **+1.5\~2**
오른다. 뒤의 셋이 절반인 것은 의도다: 주축은 여전히 경기장에서 자란다.

- **협상은 타결에만 붙는다.** 오퍼를 넣는 것은 공짜라, 넣기만 해도 오르면 아무 선수에게나
  1파운드를 부르는 것이 훈련이 된다.
- **훈련은 결산 횟수가 아니라 세션 수로 센다.** 결산당 고정값이면 `advance_time`을 하루씩
  쪼개는 것만으로 XP가 불어난다 — 세션 수는 어떻게 쪼개도 같다. 소수로 쌓이고 100에서
  한 칸이 되는 것은 다른 축과 같다.
- **그래서 XP를 주는 것도 결산이 아니라 코어다** — 세션을 소화하는 자리(`dailyTick`)에서
  붙는다. 판정에 매달아 두면 mock 모드나 토큰 예산 상한처럼 **결산이 아예 돌지 않는**
  시즌의 감독은 훈련장에서 아무것도 배우지 못하고, 결산 도구가 한 턴에 두 번 불린 감독은
  두 배로 배운다 ([../llm/agents.md](../llm/agents.md) §4).

## 4. 평판 3축 — 세계가 보는 눈

보드 · 언론 · 선수단, 각 0\~100. **능력치와 다른 물건이다** — 능력치는 감독이 가진 것,
평판은 세계가 그를 보는 눈이다(`media`는 평판에만 있는 축이고 능력치 5축에는 없다).

| 무엇                       | 보드            | 언론     | 선수단  |
| -------------------------- | --------------- | -------- | ------- |
| 경기 승 / 패 (친선 제외)   | +2 / −2         | —        | +2 / −2 |
| 시즌 리뷰 (기대 충족/미달) | +8 / −8         | —        | —       |
| 유럽 대항전 우승 / 결승    | +10 / —         | +10 / +4 | —       |
| 국내 컵 우승 / 결승        | +6 / —          | +8 / +3  | —       |
| 보드 경고                  | −6              | —        | —       |
| 기자회견                   | 스탠스별 (아래) |          |         |

**기자회견이 평판을 움직이는 유일한 판정형 스킬이다** — 팀토크·면담은 사기만 건드린다.
폭은 `PRESS_BAND`(4) × 회견 무게(1\~3), 즉 최대 ±12다.

| 스탠스                 | 보드 | 언론 | 선수단 |
| ---------------------- | ---- | ---- | ------ |
| 감싸기(`defend`)       | −0.2 | −0.4 | +1.0   |
| 책임 인정(`own`)       | +0.6 | +0.2 | +0.6   |
| 공개 비판(`criticise`) | +0.3 | +0.8 | −0.9   |
| 도발(`bold`)           | −0.3 | +1.0 | +0.4   |
| 말 아끼기(`deflect`)   | 0    | −0.3 | 0      |
| **방치·거절**          | −0.3 | −1.0 | +0.2   |

**공짜인 스탠스는 없다.** 무게는 성적 압박(최근 최대 4경기가 전부 무승 — 최소 3경기)이면
3, 큰 이적이면 2, 그 밖엔 1\~2다. 상세는 [../data/people.md](../data/people.md).

평판을 **읽는** 자리는 셋이다 — 영입 협상에서 `(언론+보드)/2`, 재계약에서
`(언론+선수단)/2`, 설득 논거 `manager_reputation`에서 세 축 평균(60 이상이어야 통한다).

## 5. 보드와 자리 — 경고가 먼저, 경질은 나중

기대치는 구단 등급이 정한다. **난이도는 별도 옵션이 아니라 이 표다.** 등급은
**세이브의 값**(`tierOfTeamIn`)이고 시즌마다 다시 매겨지므로, 이 표가 가리키는 줄도
시즌 경계에서 바뀔 수 있다 — 바뀌면 롤오버 다이제스트가 알린다
([../data/team.md](../data/team.md) §2.1).

**문턱은 순위가 아니라 리그의 모양에서 나온다** (`core/league-shape.ts`). 재료는 둘,
**리그 팀 수**와 **강등 칸 수**(`RELEGATION_SLOTS` 3)다.

- **잔류선** = 팀 수 − 강등 칸 수 · **강등선** = 잔류선 + 1 · **꼴찌** = 팀 수
- **n% 자리** = `round(팀 수 × n)` — 1위와 꼴찌 사이로 자른다

| 팀 tier           | 보드 기대                | 위험 순위  | AI 감독이 잘리는 순위 |
| ----------------- | ------------------------ | ---------- | --------------------- |
| 1 (빅클럽)        | 10% 자리 — 우승 경쟁     | 30% 자리   | 50% 자리              |
| 2 (상위권)        | 30% 자리 — 유럽 대항전권 | 50% 자리   | 70% 자리              |
| 3 (중위권)        | 60% 자리                 | 75% 자리   | 90% 자리              |
| 4 (승격팀·잔류권) | **잔류선** — 잔류        | **강등선** | **꼴찌**              |

그 식이 실제로 앉는 자리:

| 팀 tier | 20팀 (EPL·라리가·세리에 A) | 18팀 (분데스리가·리그 1) |
| ------- | -------------------------- | ------------------------ |
| 1       | 2 · 6 · 10                 | 2 · 5 · 9                |
| 2       | 6 · 10 · 14                | 5 · 9 · 13               |
| 3       | 12 · 15 · 18               | 11 · 14 · 16             |
| 4       | 17 · 18 · 20               | 15 · 16 · 18             |

**보드는 순위만 걸지 않는다 — 구단주가 직접 온다.** 순위가 기대 아래로 처져 있는
동안 압력이 쌓이고 임계를 넘으면 구단주가 감독실 문을 두드린다 (다가옴의 `results`
주제 — [../data/people.md](../data/people.md) §8). 경고와 눈금을 따로 두는 이유는
하는 일이 다르기 때문이다.

| 무엇      | 경고 (`reviewUserSeat`)    | 구단주의 다가옴                           |
| --------- | -------------------------- | ----------------------------------------- |
| 세는 것   | 위험 순위 아래에 있는가    | 기대 순위 아래에 있던 **날 수**           |
| 주기      | 한 달에 한 번까지          | 압력 100 · 200 · 300 · 400                |
| 남기는 것 | 보드 평판 −6 · 경고 카운터 | 감독이 **답할 자리** — 답이 평판을 옮긴다 |
| 끝        | 3회에서 경질 판정으로 간다 | 계단 3에서 멈춘다 (경질과 무관하다)       |

⚠️ **두 눈금이 같은 사실을 보되 자리를 다투지 않는다.** 경고는 감독의 거취를 재고
다가옴은 감독에게 말할 자리를 준다 — 잘 답해도 경고는 지워지지 않는다. 경고를 지우는
것은 순위뿐이다.

**감독의 자리**(`reviewUserSeat` — tick이 매일 본다):

1. 리그 12경기를 치르기 전에는 보지 않는다.
2. **순위가 기대 목표 이내면 경고가 하나 지워진다** — 되돌릴 수 있어야 압박이 이야기가
   된다.
3. 순위가 **위험 순위 이하로 처졌고**(표의 숫자보다 아래) **마지막 경고로부터 한 달**이
   지났으면 경고한다 — 보드 평판 −6. **경고 수는 3에서 멈춘다**: 3회에 이른 뒤로도 한 달에
   한 번 평판은 깎이지만 카운터는 3/3에 서 있는다(그게 마지막 경고라는 뜻이다).
4. **경고 3회째 + 강등선 아래 두 자리 + 보드 평판 25 이하**가 모두 겹칠 때만 경질된다
   (20팀이면 19·20위, 18팀이면 17·18위). `state.dismissal`이 서면 감독은 그날부로 이
   구단의 사람이 아니다 — 그날 하루만 시계가 멈춰 서고, 다음 날부터는 **무직으로 흐른다**
   (§5.1).

**경고 횟수는 화면에 서 있다.** 커리어 화면의 머리글이 세 칸으로 그리고(찬 칸이 받은
경고다), GM의 `get_career`도 같은 숫자를 말한다. digest 한 줄은 지나가지만 카운터는
남아야 한다 — 끝이 예고 없이 오면 사건이 아니라 사고다.

⚠️ **이 문턱은 AI보다 훨씬 관대하고, 그 비대칭은 의도한 것이다** — 감독에게는 **경고가
먼저 오기 때문**이다. 같은 문턱을 쓰면 우승 경쟁이 기대인 구단에서 10위만 해도 경고 한
번 없이 시즌 중에 자리가 없어진다.

**AI 구단의 벤치도 바뀐다**(`runManagerMarket`) — 부임 75일이 지나고 8경기를 치른 구단이
등급별 문턱 아래로 처지면 하루 **9%** 확률로 결단한다(하루 2건 상한). 후임은 새 이름과
새 전술 역량치(이전 값 + `randInt(−4, 10)`, 50\~92로 자름)를 갖고, **새 감독 효과**로 그 선수단의
체력이 +6 · 폼이 +0.1 오른다. 우리 리그 안의 경질만 감독의 소식에 오른다.

### 5.1 경질 뒤 — 무직의 하루, 제안, 부임

**경질은 끝이 아니라 상태다.** `state.dismissal`이 선 날부터 감독은 무직이고, 시계는
그대로 흐른다. 경질과 동시에 옛 구단은 새 AI 감독을 세우고(`managerName`·`managerSince`),
**진행 중이던 협상은 전부 사라진다** — 감독이 없는 구단의 흥정이다.

**경질 카드는 사실만 남는다** (overview.md §1 철칙 4 — 문장은 화면·GM이 쓴다):

```ts
dismissal: {
  on: string,          // 경질일
  season: number,
  teamId: string,      // 어느 구단에서
  tier: 1 | 2 | 3 | 4, // 그 구단의 등급
  position: number,    // 그날의 리그 순위
  target: number,      // 보드가 걸었던 기대 순위
  expectation: string, // 기대의 이름 — `boardExpectationOfTier`의 label
}
```

⚠️ 옛 세이브는 카드 대신 평가 문장(`reason`)을 들고 있다 — 화면이 그것을 폴백으로 읽는다
(둘 다 optional, 세이브 버전 유지).

**무직의 하루** — tick은 그대로 돌지만 감독의 일이 없다:

| 도는 것                                         | 서는 것                                |
| ----------------------------------------------- | -------------------------------------- |
| 리그·컵·대항전 전 경기 (옛 팀 경기도 간이 시뮬) | 경기일 — 감독은 경기에 들어가지 않는다 |
| AI 이적·재계약·무소속 영입·감독 경질과 선임     | 훈련 편성·소화와 훈련 XP               |
| 월간 재정·성장, 주급, 부상 회복, 이적창         | 들어오는 이적 오퍼·계약 만료 예고      |
| **감독직 제안**                                 | 벤치 불만, 협상 기한 앞에서 멈춰 서기  |

가르는 것은 **`managedTeamId(state)` 하나**다 — 무직이면 `null`이라, 감독 팀으로
갈라지던 자리가 전부 "그런 팀 없음"으로 떨어지고 옛 구단은 `tickOtherClubs`가 도는 AI
클럽의 길로 넘어간다. **시즌 전환에서도 그렇다**: 계약 자동 갱신을 감독 팀만 건너뛰므로,
무직으로 시즌을 넘기면 옛 구단은 AI처럼 자동 갱신한다(안 그러면 감독도 없는 구단의
선수단이 통째로 걸어 나간다).

**제안이 붙은 날은 시계가 멈춘다** (`stopped: "attention"`) — 10일 뒤 사라지는 것이라
감독이 모르는 채 지나가면 안 된다.

**무직인 감독이 부를 수 있는 조작 도구는 `accept_manager_offer` 하나다.** 경질돼도
`userTeamId`는 옛 구단을 가리키므로(그 구단의 장부는 계속 돌아야 한다) 막지 않으면 GM이
남의 구단의 라인업을 짜고 남의 선수를 판다. 조회는 그대로 연다 — 무직 감독도 세계를 읽을
수는 있다. **기자회견도 막힌다**: 미디어 평판이 곧 다음 자리의 문턱이라, 무직 중의 회견
반복이 승진 경로가 된다.

시즌이 무직 중에 끝나면 **그 시즌은 커리어에 남지 않는다** — `SEASON_RECORD`·트로피·
업적·보드 평판 ±8은 자리에 있던 감독의 것이다. 리그 상금·성과 보너스처럼 구단이 치르는
것은 그대로 결산된다.

**제안은 AI 경질 자리에서 온다.** 무직인 동안 `runManagerMarket`이 어느 구단의 감독을
자르면, 그 자리가 이 감독의 눈높이에 맞을 때 제안이 붙는다.

- **평판이 등급 문턱을 넘어야 부른다.** 평판은 `(보드 + 미디어) / 2`이고 문턱은 tier 1이
  **70** · 2가 **55** · 3이 **40**, tier 4는 없다. 경질 직후의 보드 평판은 25 이하라 대개
  tier 3·4에서만 부르고, 그 자리에서 성적을 내 평판을 회복해야 위가 열린다.
- 문턱을 넘은 자리는 하루 **20%** 확률로 제안이 된다. 한 구단은 한 번만 부른다.
- 제안은 **10일** 뒤 만료된다. 열린 제안이 있는 동안에는 새 제안이 붙지 않는다 — 감독이
  답할 자리는 한 번에 하나다.
- **120일이 지나도록 제안이 하나도 없었으면** 그다음 문턱을 넘는 자리는 확률을 건너뛰고
  반드시 부른다. 세이브가 무직으로 굳지 않게 하는 안전판이다.

**수락은 언제든 된다** — 시즌 중이어도 그날부로 부임한다(`acceptManagerOffer`). 상태
전이는 넷이다:

1. `userTeamId`가 새 구단이 되고, 그 구단의 `managerName`이 감독 이름 · `managerSince`가
   오늘이 된다.
2. `dismissal`이 지워지고 남은 제안은 만료된다.
3. 보드 경고(`boardWarnings`·`lastWarnedOn`)와 **다가옴의 압력**(§5의 표 · people.md §8)이
   지워진다 — 앞 구단의 것을 지고 가지 않는다.
4. 기본 훈련이 새 선수단으로 다시 깔린다.

⚠️ **부임 직후엔 자리를 보지 않는다.** 새 구단의 순위는 앞 감독이 만든 것이라
`reviewUserSeat`는 부임 **75일**(`GRACE_DAYS`)이 지나야 경고를 시작한다 — AI 구단의
유예와 같은 값이다.
⚠️ 시즌 중에 부임하면 그 시즌의 `SEASON_RECORD`는 **부임 전 경기까지 포함한 새 팀의 최종
성적**으로 남는다. 순위표가 감독이 아니라 구단 단위이기 때문이다.

**화면과 조회** — 커리어 화면 맨 위에 경질 카드와 열린 제안이 선다. 제안은 **읽는
값이다**: 버튼이 아니라 카드고, 수락은 감독이 말로 한다(`accept_manager_offer`). 상태
스냅샷과 `get_career`도 무직이면 다른 것을 싣는다 — 전술·재정·선수단·훈련은 전부 옛
구단의 것이라 그대로 실으면 GM이 아직 그 구단의 감독인 것처럼 장면을 쓴다. 그 자리에
경질 사실과 열린 제안 목록이 선다.

## 6. 커리어 기록

| 기록            | 무엇이 남나                                                | 언제                                       |
| --------------- | ---------------------------------------------------------- | ------------------------------------------ |
| `SEASON_RECORD` | 시즌 · 팀 · 최종 순위 · 승무패 · 득실 · **보드 평가 카드** | 시즌 리뷰                                  |
| `TROPHY`        | 시즌 · 대회 표시 이름 · 팀                                 | 리그 1위 · 유럽 대항전 우승 · 국내 컵 우승 |
| `ACHIEVEMENT`   | code · 시즌 · **근거 수치**                                | 시즌 리뷰의 조건 검사                      |

**시즌 리뷰(`reviewSeason`)가 한 자리에서 확정한다** — 최종 순위 → 보드 평가 카드와 평판
±8 → 리그 트로피 → 유럽·국내 컵 결산(트로피·평판·상금) → 리그 상금·성과 보너스 → 업적 →
`SEASON_RECORD` 적재. 그다음이 시즌 전환이다 ([season.md](./season.md) §6).

**보드 평가는 등급과 근거 수치로 남는다** (`SEASON_RECORD.board`) — 문장이 아니다
(overview.md §1 철칙 4).

```ts
board: {
  grade: "met" | "missed",   // 최종 순위 ≤ 기대 순위
  position: number,          // 최종 순위
  target: number,            // 그 시즌의 기대 순위
  expectation: string,       // 기대의 이름 — `boardExpectationOfTier`의 label
}
```

같은 4위가 어느 구단에서는 성공이고 어느 구단에서는 실패인 이유가 `target`에 그대로
남으므로, 커리어 표는 **그 시즌의 기대까지 함께** 보여 준다. 문장은 화면이 쓴다.
⚠️ 옛 세이브는 `board` 대신 평가 문장(`boardVerdict`)을 들고 있다 — 화면이 그것을
폴백으로 읽는다 (둘 다 optional, 세이브 버전 유지).

**업적도 코드와 근거 수치로 남는다** — 업적 이름도 설명 문장도 세이브에 없다(철칙 4).
문장이 굳으면 문구를 고쳐도 옛 세이브는 옛 문장 그대로다.

| code            | 조건                                                   | 함께 남는 수치                          |
| --------------- | ------------------------------------------------------ | --------------------------------------- |
| `champion`      | 그 리그 1위                                            | `position` · `leagueId`                 |
| `invincible`    | 리그 전 경기 무패 (20팀 38경기, 18팀 34경기)           | `matches` · `leagueId`                  |
| `ucl-spot`      | **그 리그의 UCL 티켓 안**                              | `position` · `leagueId`                 |
| `sharpshooter`  | 우리 팀 시즌 15골 이상 최다 득점자                     | `gamePlayerId` · `playerName` · `goals` |
| `survivor`      | tier 4 구단으로 **잔류선** 이내 (20팀 17위, 18팀 15위) | `position` · `leagueId`                 |
| `cup-winner`    | 국내 컵 우승                                           | `competitionId`                         |
| `euro-champion` | 유럽 대항전 우승                                       | `competitionId`                         |

순위·경기 수를 쓰는 셋은 §5와 같은 식에서 나온다.

**`ucl-spot`은 리그를 본다.** 티켓 수는 리그마다 다르므로(EPL·라리가·세리에 A·분데스리가
5장, 리그 1 4장 — [competition.md](../data/competition.md)) 경계도 리그마다 다르고, 티켓이
없는 2부에서는 몇 위를 해도 붙지 않는다. 순위 하나로 자르면 강등된 2부의 4위에 "유럽 진출"이
붙는다.

**컵·대항전 우승은 대회마다 하나씩** 붙는다 — 같은 시즌에 리그컵과 FA컵을 둘 다 들면 둘 다
남는다(코드·시즌·대회가 모두 같을 때만 중복으로 본다). 트로피와 겹치지만 트로피는 대회의
기록이고 업적은 감독의 기록이다.

**코드가 곧 무엇을 이뤘는가다.** 코드→업적 이름은 `achievementTitle`(`packages/domain`)이
한 자리에서 주고, 근거 문장은 그것을 읽는 쪽(화면·`get_career`)이 수치로 쓴다.
⚠️ 옛 세이브는 `top4`(리그를 안 보는 4위 이내)와 이름·설명 문장을 들고 있다 — 문장은 더는
읽지 않고, 코드는 옛 이름 그대로 보여 준다 (세이브 버전 유지).

**화면과 조회** — 커리어 뷰는 오각형(다섯 축) + 평판 막대 3줄 + **보드 경고 3칸** +
트로피 보관함 + 업적 + 시즌 기록 표다. 막대 다섯 줄은 값을 하나씩 비교하게 만들 뿐이고
도형은 모양 하나로 성향을 말한다. **다음 칸까지 남은 XP는 오각형의 축 위에** 얹는다 —
축값 옆에 서야 "이 축이 지금 자라는 중인가"가 그 자리에서 읽힌다. GM은 `get_career`로
같은 것을 읽는다 — **지난 시즌의 개별 경기 결과는 남지 않고 시즌 단위 요약만 있다.**

## 7. ⚠️ 불변식

- **온보딩 해석은 순수 함수로 남긴다.** 같은 배경·같은 팀이 다른 능력치를 내면 시작이
  운이 된다.
- **부임 구단은 하한이지 가산이 아니다.** 가산으로 바꾸면 빅클럽에서 시작하는 것이 곧
  더 나은 감독이 되는 것이 되고, 약팀에서 시작하는 서사가 손해가 된다.
- **경질 문턱은 이직 경로와 한 몸이다.** 감독의 문턱이 AI보다 관대한 것은 경고가 먼저
  오기 때문이고, 그 뒤를 제안이 받는다. 문턱을 AI와 같게 조이려면 제안이 오는 빈도가
  먼저 그것을 감당해야 한다 (§5.1).
- **경고는 지워질 수 있어야 한다.** 되돌릴 수 없는 압박은 이야기가 아니라 카운트다운이다.
- **기대치는 등급 표에서만 온다.** 기대와의 *차이*로 재면 잔류가 기대인 구단은 꼴찌를
  해도 차이가 3이라 강등권 감독이 영원히 안 잘린다.
- **`SEASON_RECORD`·`TROPHY`는 팀 id를 함께 갖는다** — 감독이 팀을 옮겨도 기록이 감독에게
  남아야 한다.
- **평판과 능력치를 한 값으로 합치지 않는다.** 하나는 감독이 가진 것이고 하나는 세계가
  보는 눈이라, 합치면 "잘하는데 안 알려진 감독"이 표현되지 않는다.
- **같은 말은 두 번 남지 않는다.** 면담·팀토크·주장 지명은 반복해도 사기·체력·XP·정착을
  더 쌓지 않는다. 반복이 이득이면 최적 전략은 말 연타가 되고, 감독의 판단은 버튼 연타가 된다.

## 8. 미해결

- **보드가 거는 것은 순위 하나다.** 구단주가 먼저 말을 거는 길은 생겼지만(§5) 그
  자리에서도 재료는 `competition/season.ts`의 `boardExpectation`이 돌려주는 순위
  목표뿐이다 — 영입 승인·예산 상한·특정 선수 기용 같은 **조건부 요청**이 없고, 감독의
  답이 그 요청을 이행했는지 판정하는 길도 없다.
- **이직은 제안 수락까지다** (§5.1). 연봉·계약 기간·이적 예산을 두고 흥정하는 자리가
  없고, 감독이 먼저 자리를 노크할 수도 없다.
- **경질이 커리어 표에 남지 않는다** — 부임하면 `dismissal` 카드가 지워지고, 잘린 시즌은
  `SEASON_RECORD`가 없어 그 해가 통째로 비어 보인다.
- 전 축이 상한(`skills/index.ts`의 `MANAGER_ATTR_CAP` 90)에 닿은 시나리오의 게임감이
  검증되지 않았다.
